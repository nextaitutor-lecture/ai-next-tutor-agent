## 제작 기준
- 인트로 및 핵심 메시지를 유지하고, 결과 선공개는 짧게 구성한다.
- 동일한 선택 결과는 도입에서 action만, 본 실행에서 action과 reason을 보여주어 반복 설명을 줄인다.
- 코드 작성은 목표·현재 상태·가능한 행동 세 항목에 집중한다.
- 학생은 시작의 막막함과 선택·실행의 의문을 대변한다. 이미 아는 사람처럼 질문하지 않는다.
- 대부분은 강사·편집기·터미널 화면을 사용한다. 한글 요약과 강조 자막은 기존 화면 위에 표시한다.
- AI가 상황을 스스로 만든다고 설명하거나 티켓 예약까지 구현했다고 약속하지 않는다.
- 전체 분량은 약 4~5분을 목표로 하되 입력 대기와 전환은 편집한다. 표의 시간은 본 장면 기준이다.

## 실행 소스와 촬영의 일치
현재 agent27/02_decide.py는 규칙 기반이다. 실제 LLM 호출 함수 구현 전에는 ‘LLM이 선택’ 장면을 촬영할 수 없다.
대본은 실제 LLM 호출을 전제로 작성했으며 이 문서만으로 실행 소스가 수정되지는 않는다.
API 키를 화면에 노출하지 않고, 실제 모델 응답에 따라 선택 이유 자막과 대사를 조정한다.

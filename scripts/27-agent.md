# #27. AI Agent란 무엇인가?

## 인트로

**강사**

AI가 나 대신 일정을 잡고, 티켓을 예매하고, 쇼핑까지 해준다.  
이런 AI 에이전트 소개, 한 번쯤 들어보셨죠?

그런데 이런 AI 에이전트, 우리도 직접 만들 수 있습니다.

**학생**

제가요? 어디서부터 만들어야 할지 감도 안 잡히는데요.

**강사**

그렇죠. 저 말만 들으면 뭔가 엄청난 걸 만들어야 할 것 같잖아요.

그래서 이번 시간부터는 아주 작게 시작해서,  
하나씩 기능을 붙여보려고 합니다.

우리가 만들 건 **나만의 출장 비서**예요.

자, 이렇게 일을 시켜보겠습니다.

**“다음 주 부산 출장 준비해줘.”**

이 말을 들은 우리 비서,  
**가장 먼저 뭘 해야 할까요?**


## STEP 1. 출장 준비를 맡기면 무엇부터 할까?

**강사**

직접 만들어보려면, 먼저 코드를 실행할 개발환경이 필요하겠죠.

필요한 개발환경과 예제 코드는 영상 설명란의 GitHub에 정리해두겠습니다. 같이 따라 하실 분들은 먼저 준비해주시고요.

**[화면 — 안내 자막]**

개발환경 설정 · 예제 코드  
영상 설명란 링크 참고

**강사**

그럼 출장 준비를 맡겼을 때, AI가 무엇부터 하는지 확인할 작은 버전부터 만들어보겠습니다.

우선 AI가 사용할 수 있는 기능은 세 가지로 해볼게요. 일정 확인, 교통편 검색, 숙소 검색입니다. 이 중 무엇부터 할지는 AI가 골라보게 하겠습니다.

자, “다음 주 부산 출장 준비해줘.”라고 요청해보겠습니다. AI는 무엇부터 하려고 할까요?

**[화면 — 실제 터미널 실행]**

```text
Selected Action | 선택한 행동
check_calendar    캘린더 확인

Reason | 선택 이유
교통편과 숙소를 확인하려면
먼저 정확한 출장 날짜가 필요함
```

**강사**

캘린더를 먼저 확인하겠다고 하네요. 출장 날짜부터 알아야 교통편과 숙소를 찾을 수 있다는 거죠.

**학생**

그런데… 지금 캘린더를 확인한 거예요? 아니면 확인하겠다고 고르기만 한 거예요?

**강사**

지금은 캘린더를 확인하겠다고 고른 겁니다. 실제로 출장 날짜를 가져온 건 아직 아니고요.

그럼 AI는 뭘 보고 캘린더부터 확인하겠다고 골랐을까요? 우리가 AI에게 전달한 정보를 한번 보겠습니다.

먼저 목표는 ‘다음 주 부산 출장 준비’이고요. 현재 알고 있는 정보에는 출장 날짜가 비어 있습니다.

**[화면 — AI에게 전달한 정보]**

```text
Goal | 목표
다음 주 부산 출장 준비

Current State | 현재 알고 있는 정보
출장 날짜: 알 수 없음
```

**강사**

앞에서 배운 Context죠. AI가 판단할 때 참고하도록, 목표와 현재 알고 있는 정보를 함께 전달한 겁니다.

여기에 AI가 사용할 수 있는 기능도 함께 알려줍니다. 아까 정한 캘린더 확인, 교통편 검색, 숙소 검색이고요.

**[화면 — Context에 기능 목록 추가]**

```text
Available Actions | 사용 가능한 기능
check_calendar      캘린더 확인
search_transport    교통편 검색
search_hotel        숙소 검색
```

**강사**

이 정보를 LLM에게 전달하면서 이렇게 요청합니다. “현재 상황에서 다음에 할 일을 하나 골라주고, 그 이유도 알려줘.”

**[화면 — LLM에게 전달하는 Context와 요청]**

```text
목표
다음 주 부산 출장 준비

현재 알고 있는 정보
출장 날짜: 알 수 없음

사용 가능한 기능
check_calendar      캘린더 확인
search_transport    교통편 검색
search_hotel        숙소 검색

LLM에게 요청
현재 상황에서 다음에 할 일을 하나 골라주고,
그 이유도 알려줘.
```

**강사**

그럼 이 정보를 코드에서는 어떻게 전달했는지 보겠습니다.

목표는 `goal`에, 현재 알고 있는 정보는 `current_state`에 담았습니다. 출장 날짜는 아직 모르니까 `None`으로 두고요.

**[화면 — 코드]**

```python
goal = "다음 주 부산 출장 준비"

current_state = {
    "trip_date": None  # 출장 날짜: 아직 모름
}
```

**강사**

사용할 수 있는 기능은 `available_actions`에 담습니다. 여기에는 우선 기능의 이름만 적어둡니다.

**[화면 — 코드 추가]**

```python
available_actions = [
    "check_calendar",    # 캘린더 확인
    "search_transport",  # 교통편 검색
    "search_hotel"       # 숙소 검색
]
```

**강사**

그리고 이 세 가지 정보를 LLM에 전달해, 다음 행동을 선택하도록 합니다.

**[화면 — LLM 호출 부분을 간략히 표시]**

```python
# LLM 호출을 감싼 함수
decision = ask_llm(
    goal,
    current_state,
    available_actions
)
```

**강사**

이제 다시 실행해보겠습니다. 방금 본 목표와 현재 정보, 기능 목록을 보고 어떤 행동을 고르는지 보세요.

**[화면 — 터미널 실행 결과]**

```text
Selected Action | 선택한 행동
check_calendar    캘린더 확인

Reason | 선택 이유
교통편과 숙소를 확인하려면
먼저 정확한 출장 날짜가 필요함
```

**강사**

캘린더 확인을 골랐네요. 우리가 코드에 “캘린더부터 확인해”라고 정한 건 없었죠. 출장 날짜를 모른다는 정보를 보고, LLM이 다음 행동을 선택한 겁니다.

**학생**

뭘 보고 고른 건지는 알겠어요. 그럼 이제 고른 기능을 실제로 실행하게 하려면 어떻게 해야 해요?
